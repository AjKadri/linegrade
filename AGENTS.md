# Agent rules for LineGrade
- No task is reported done without pasting its acceptance check output (command + result).
- Never commit .env, PLAN.md, HANDOFF.md or agent notes.
- No Co-Authored-By or other AI attribution trailers in commits.
- Synthetic data must be labelled as synthetic in UI and docs. Fee savings are always labelled "estimate".
- Sandbox only. Credentials stay server-side.
